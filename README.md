# Cphas Hardwares Limited - Website

A modern, scalable website built with Next.js for Cphas Hardwares Limited.

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open http://localhost:3000 in your browser.

## Pages
- Home - Hero section with features and lead form
- Products - Product catalog with filtering and pricing
- Services - Service offerings
- About - Company information
- Gallery - Photo gallery
- Contact - Contact form and business info

## Features
✅ Responsive Design
✅ Product Catalog with Prices
✅ Lead Generation Form
✅ Social Media Integration (Facebook, WhatsApp, Instagram, Twitter)
✅ Contact Management
✅ Modern UI with Tailwind CSS

## Tech Stack
- Next.js 14
- React 18
- Tailwind CSS
- React Icons
